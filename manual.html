Core Understanding

What is this project in 60 Seconds?

1

The Problem: Cognitive Drift

AI agents remember everything forever. When a doctor writes: "Stop Albuterol, start Flovent", standard search retrieves both notes because they both mention asthma. The AI gets confused and gives dangerous advice.

2

The Solution: The Auto-Healing Engine

Cogni-Intent works like white blood cells for AI memory. It scans the memory database, groups related notes together, spots contradictions, and automatically combines them into a single verified "Golden Fact".

3

The Result: Zero Data Loss

Old notes are not deleted (which would break medical malpractice laws). Instead, they are archived as historical ancestors in a visual lineage graph, while the AI only retrieves the active Golden Fact.

Quick Answers

Frequently Asked Questions

help Do I need to install Python, Docker, or ChromaDB to use this website?

No! The website is built with a dual-engine architecture. If you simply view it in your browser (or on GitHub Pages), a high-fidelity client-side NLP & MLOps engine runs in the background. If you do run the Python FastAPI backend locally, it seamlessly connects to that as well.

help What does the "Memory Health Score" (MHS) mean?

MHS is a health score from 0.0 to 1.0. A score of 1.0 means every memory in the active pool is consistent and clear. If contradictory statements appear, MHS drops. If it drops below 0.75, the auto-healing loop immediately steps in to merge conflicts and restore clarity.

help Can I enlarge the system diagrams?

Yes! Click on any blueprint or diagram on any page (or click "Enlarge" / "Click to zoom"). A high-resolution lightbox modal will pop up. You can press the Esc key or click the close button to exit.

help Can I test my own custom memory statements?

Yes! Go to the Simulation Lab, click "Custom Playground", type in any conflicting facts (e.g. "Fact 1: John lives in Paris", "Fact 2: John moved to Tokyo"), and click "Inject & Load Into Lab"!
